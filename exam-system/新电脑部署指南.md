# 在线考试系统 · 新电脑部署指南

> 这份文档教你在一台全新的 Windows 电脑上，从零把这个系统跑起来。
> 全程只需要装 3 个软件，不需要装 Maven（项目自带）。

---

## 一、先在旧电脑上拷贝这些文件（U盘 / 网盘都行）

| 拷什么 | 位置 | 说明 |
|---|---|---|
| **后端项目** `exam-system` 整个文件夹 | `D:\Java project\exam-system` | 里面的 `target`、`logs` 文件夹可以删掉再拷，能小很多 |
| **前端项目** `exam-web` 整个文件夹 | `D:\Java project\exam-web` | ⚠️ **删掉 `node_modules` 文件夹再拷**（几百 MB 且换电脑后无效，新电脑会重新生成） |
| **数据库备份** `exam_system_full_backup.sql` | `exam-system\database\` 里 | 已经帮你导出好了，含全部表 + 数据（账号、题库、成绩等），跟着代码一起走 |

> 💡 如果嫌手动删麻烦：不删也能用，只是拷贝慢。`node_modules` 到了新电脑反正要重新 `npm install`。

---

## 二、新电脑安装 3 个软件

### 1. JDK 17（后端运行环境）

- 下载：搜「Adoptium JDK 17」或去 https://adoptium.net ，选 **Windows x64 .msi**
- 安装时一路下一步，默认装到 `C:\Program Files\Eclipse Adoptium\jdk-17.x.x`
- **安装时勾选「Set JAVA_HOME」选项**（新版 msi 有这个勾选框，勾了就不用手动配）

**手动检查/配置 JAVA_HOME**（如果 mvnw 报错说找不到 JAVA_HOME 才需要）：

1. 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量
2. 「系统变量」里点「新建」：
   - 变量名：`JAVA_HOME`
   - 变量值：JDK 安装目录（如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.11.9`）
3. 点确定保存

### 2. Node.js（前端运行环境）

- 下载：https://nodejs.org 装 **LTS 版本**（18 或更高都行）
- 一路下一步即可，自动配好环境变量
- 验证：打开新的 CMD，输入 `node -v` 能显示版本号就是成功

### 3. MySQL 8.0（数据库）

- 下载：搜「MySQL 8.0 installer」或 https://dev.mysql.com/downloads/installer
- 安装类型选 **Server only** 就够
- ⚠️ **root 密码必须设成 `123456`**——后端配置文件里写死了这个密码，设别的就要改代码里的 `application.properties`

---

## 三、导入数据库（5 分钟）

1. 把两个项目文件夹放到新电脑，比如还是放 `D:\Java project\` 下
2. 按 `Win + R`，输入 `cmd` 回车，打开黑窗口
3. 复制下面整条命令，粘贴进去回车（右键=粘贴）：

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p123456 --default-character-set=utf8mb4 < "D:\Java project\exam-system\database\exam_system_full_backup.sql"
```

> - 备份文件里自带「创建数据库」语句，**不需要提前建库**
> - `--default-character-set=utf8mb4` 是防止中文乱码的，**千万别省略**
> - 没报错就是成功。可以输 `mysql -u root -p123456 -e "SELECT COUNT(*) FROM exam_system.sys_user;"` 验证，应该显示 131

---

## 四、启动后端（第一次约 5~10 分钟，之后秒开）

继续在 CMD 黑窗口里操作：

```bat
:: 1. 进入后端目录（按你的实际路径改）
cd /d "D:\Java project\exam-system"

:: 2. 第一次运行：打包（mvnw 会自动下载 Maven 和所有依赖包，耐心等）
mvnw.cmd package -DskipTests

:: 3. 启动（java 已随 JDK 装好并在 PATH 里）
java -jar target\exam-system-0.0.1-SNAPSHOT.jar --server.port=8080
```

看到日志最后出现 `Tomcat started on port 8080` 就说明成功了。
**这个黑窗口别关**，关了后端就停了。

> 💡 如果第 3 步提示 `java 不是内部或外部命令`，说明 JDK 没进 PATH，
> 就用完整路径启动：`"C:\Program Files\Eclipse Adoptium\jdk-17.xxx\bin\java.exe" -jar target\...`

---

## 五、启动前端

**再开一个新的** CMD 黑窗口（后端那个别动）：

```bat
:: 1. 进入前端目录
cd /d "D:\Java project\exam-web"

:: 2. 第一次运行：安装依赖（国内网络慢的话，先执行下面那行切换镜像源，只需一次）
::    npm config set registry https://registry.npmmirror.com
npm install

:: 3. 启动开发服务器
npm run dev
```

看到类似 `Local: http://localhost:5173/` 就成功了。
**这个窗口也别关。**

## 七、常见坑速查

| 现象 | 原因和解决办法 |
|---|---|
| 导入 SQL 后题目/名字变问号或乱码 | 导入时忘了加 `--default-character-set=utf8mb4`，删库重新导 |
| `mvnw.cmd` 报「找不到 JAVA_HOME」 | 回看第二步，配好 JAVA_HOME 后**重开一个 CMD** 再试 |
| `npm install` 卡住不动或报网络错误 | 先执行 `npm config set registry https://registry.npmmirror.com` 再重试 |
| 后端启动报「Communications link failure」 | MySQL 服务没启动：`Win+R` 输 `services.msc`，找到 `MySQL80` 右键启动 |
| 启动后端报「Port 8080 already in use」 | 上次的进程还活着：`netstat -ano \| findstr :8080` 找到 PID，再 `taskkill /PID 那个数字 /F` |
| 前端页面打得开但一直转圈/报错 | 后端没启动成功，回到第四步看后端黑窗口的报错 |
| 手机想通过局域网访问 | 前端 dev 默认只监听本机；且防火墙要放行端口（详见踩坑记录：WLAN 常被判公用网络，需加入站规则） |

## 八、日常启停顺序（记这个就行）

```
开机要用系统时：
  ① 确保 MySQL 服务在跑（一般装完是开机自启的）
  ② 启动后端：java -jar target\exam-system-0.0.1-SNAPSHOT.jar --server.port=8080
  ③ 启动前端：npm run dev
  ④ 浏览器开 localhost:5173

不用了：两个黑窗口各按 Ctrl+C（或直接点 × 关掉）即可
```
